## 🧾 Descrição Geral

Aplicativo de 3 telas que simula o cadastro de clientes da loja virtual **Tem de Tudo**. O nome do cliente é coletado e exibido com mensagem personalizada.

## 🚀 Funcionalidades

- Tela de boas-vindas com logomarca;
- Tela de formulário com campo de nome;
- Tela de confirmação com mensagem e imagem;
- Navegação entre 3 Activities.

## 💡 Processo de Desenvolvimento

Pratiquei o uso de `Intent`, `Bundle`, `TextInputLayout`, `ImageView` e `TextView` dinâmico. Destaque para a troca de dados entre Activities e personalização da mensagem final.

## 📦 Como Executar o App

Você pode utilizar **qualquer uma das opções abaixo** para abrir e testar o projeto:

### ✅ Opção 1: Usando o repositório GitHub

1. Clone este repositório:  
   `git clone https://github.com/Cenedeze/Questao03-N1`

2. Abra o projeto no Android Studio;

3. Conecte um dispositivo ou inicie um emulador;

4. Compile e execute o projeto.

### ✅ Opção 2: Usando o projeto compactado

1. Baixe e extraia o arquivo `.zip` disponível no repositório:  
   [`Questao03.zip`](https://github.com/Cenedeze/Questao03-N1/blob/main/Questao03-N1/Questao03.zip)

2. Abra a pasta extraída no Android Studio;

3. Execute o projeto normalmente.

---

📲 **Instalação direta do app:**  
Tanto na pasta do projeto quanto no `.zip` extraído, você encontrará o arquivo **`questao3.apk`**, que pode ser instalado diretamente em um dispositivo Android.
